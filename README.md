# zuzazi-media

Public media for @zuzazicreations Instagram posts, scheduled through Metricool.

- `posts/<date>/` slides (1.jpg, 2.jpg ...) or `reel.mp4` for each scheduled post
- `tools/` the carousel and reel builders and the white logo
- `logs/<date>.txt` one line per post (type, pillar, topic, DM keyword, hashtags, stock media ids)

Stock photos and videos come from Pexels (free to use under the Pexels license).
